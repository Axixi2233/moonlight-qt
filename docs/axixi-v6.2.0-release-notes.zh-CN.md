# Moonlight Axixi 6.2.0 交付与验收说明

本次将上游 v6.2.0（`de2467e433821664cdd2224aad8c89a625be1ad9`）合并到 Axixi master 原提交 `18c9f089fdb020dadea6694ca6b7d242deb4320d`，包含 250309 版本之后的 3 月 19 日 Linux 统计信息居中修改。工作分支为 `sync/upstream-v6.2.0`；原 master 保持不变，未推送或发布。

## 交付文件

- `Moonlight-Axixi-6.2.0-x64.zip`：Windows x64 便携版。
- `Moonlight-Axixi-6.2.0-x64-Setup.exe`：Windows x64 安装器，包含 x64 VC++ 运行库安装项。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。

文件位于仓库的 `build/artifacts/`。应用内部版本为 6.2.0，Windows 文件版本为 6.2.0.0。文件未经代码签名。本次只交付 Windows x64 包，保留其他平台源码。

安装器已补充同版本覆盖支持，可直接覆盖官方 6.2.0 或此前 Axixi 6.2.0 包；无需先卸载。安装后请运行随包提供的 `Test-AxixiInstallation.ps1`，根据 `Moonlight-install-manifest.json` 核对主程序哈希。详见 [同版本安装修复与检查方法](axixi-same-version-install-fix.md)。该修复只更新安装器，便携 ZIP 内容保持不变。

## 保留的 Axixi 内容

- 解锁后最高 1000 Mbps 码率；未解锁时最高 150 Mbps。
- 中文完整／精简性能信息、OPPOSans-H 字体、白色文字与半透明黑底，以及原有各渲染器的居中位置。
- `showperfoverlayLite` 配置项和 `--performance-overlay-lite`／`--no-performance-overlay-lite` 命令行参数；显示开关与完整／精简模式独立。
- Ctrl+Alt+Shift+A 切换完整／精简；Guide+B 切换模式，Guide+Y 切换显示，Guide+A 切换鼠标模式，Guide+X 退出（遵守 `NO_GAMEPAD_QUIT`）。
- 紫色 SVG、配对／配置身份、安装升级标识，以及上游新增快捷键和渲染／输入修复。

同步时适配了上游微秒统计、UTF-8 截断和图像缓冲区所有权处理，并修正 QML 精简模式通知、叠加层像素格式和多行居中偏移。libplacebo 新渲染路径补齐统计信息居中；VAAPI 按窗口尺寸计算位置。

## 手动验收

测试前退出旧客户端并备份现有设置。便携版请解压到新目录，再迁移旧版配置和数据；不要直接把新文件覆盖到旧目录，以免遗留不兼容的 Qt 插件。保留旧目录便于回退。安装版保留原升级身份，验收会影响已有安装，应先备份配置。

- [ ] 旧设备列表、配对状态、分辨率、帧率、码率和精简模式偏好保留，重新启动后仍有效。
- [ ] 设置界面显示正确；码率限制符合解锁状态；手动码率在 GUI 切换分辨率／帧率时按上游设置保留。CLI 如需固定码率应显式传入 `--bitrate`。
- [ ] 串流中完整／精简统计中文清晰，数值单位正确，背景和位置正确；缩放、DPI、全屏切换、重连后仍正常。
- [ ] 键盘和 Guide 组合键逐项正常；主机不会收到不应透传的组合操作。Guide 组合之后继续移动摇杆也应检查：此处保留了原 Axixi 的状态处理，未重写既有后续轴事件行为。
- [ ] 按设备支持情况测试 H.264、HEVC、AV1、HDR、VRR，以及音视频同步、网络波动和退出重连。
- [ ] 在测试环境完成首次安装、从旧 Axixi 升级、启动和卸载；确认配置／配对保留，安装路径及快捷方式符合预期。
- [ ] 如需发布 Linux/macOS 等版本，再分别完成对应平台构建和渲染实机验收。

记录验收所用显卡、驱动、显示器、手柄、主机端版本以及发现问题时的客户端日志，便于定位设备差异。
